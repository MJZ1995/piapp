# PiPi Agent 内嵌终端 Plan v0.1

> 状态：需求理解已确认；用户已明确授权 Plan 输出后直接进入开发，不再单独等待 Plan 复核，不另行编写 PRD。

## 1. 背景与目标（Why）

为 PiPi Agent 的个人用户提供可持续交互的 App 内终端，使其能够手动运行 AGY CLI、OpenCode、Kimi CLI 等 TUI 工具，并允许 PiPi Agent 在可控权限下读取终端状态、输入内容和发送快捷键。

成功口径：

- 可在 App 内稳定运行至少 AGY CLI、OpenCode、Kimi CLI 三类交互程序。
- 多个终端可并行运行，切换聊天不终止进程。
- Agent 能准确识别当前或指定终端，按需读取输出并发送输入。
- 用户输入与 Agent 输入不会交错；高风险操作和交互式输入遵守权限规则。
- 现有聊天、文件预览、`!command` / `!!command` 能力不回归。

## 2. 范围边界（Scope）

### In Scope

- 底部可调整高度、收起和最大化的 Terminal 面板。
- 每个项目支持多个终端标签；支持创建、关闭、切换、重命名。
- 真实 PTY、ANSI 色彩、自动尺寸适配、复制粘贴及常用终端快捷键。
- 新终端从当前项目目录或 Worktree 启动，使用 macOS 登录 Shell。
- 终端搜索、当前标签纯文本输出导出。
- Agent 按名称或当前激活状态定位终端。
- 自然语言调用及 `/terminal <终端名称> <内容>` 明确调用。
- Agent 按需读取当前屏幕和最近约 200 行，单次读取设置上限。
- 保护模式、信任 Agent、风险确认、用户输入冲突队列。
- Agent 操作精简卡片：目标、内容、状态、确认情况。

### Out of Scope

- Windows、Linux 适配。
- 分屏、布局保存、完整 iTerm 功能。
- App 退出后保活、tmux 接管、进程恢复。
- 终端输出持久化或自动写入聊天记录。
- 持续向模型同步完整终端输出。
- “仅本地终端”模式及自动敏感信息脱敏。
- 替换或移除现有一次性 Shell 能力。

## 3. 用户与核心场景

目标用户：PiPi Agent 的个人使用者，需要在同一工作界面内并行使用 Agent 与多个命令行 Agent。

核心场景：

1. 在项目目录中创建终端并手动启动 AGY、OpenCode 或 Kimi CLI。
2. 在聊天中说“在 Kimi 终端输入……”，由 PiPi Agent 自动发送。
3. 使用 `/terminal` 明确指定终端和输入内容。
4. Agent 按需读取最近输出，判断交互式 CLI 当前状态后继续操作。
5. 用户正在输入时，Agent 输入进入待发送队列，避免内容交错。

## 6. 关键决策点与待定项

已决策：

- 默认目标为当前激活终端；终端名称在同一项目内唯一。
- 默认保护模式；信任状态只在当前终端进程有效。
- Shell 普通命令可自动发送，高风险命令确认。
- 交互式 CLI 输入默认确认；信任后允许自动输入，并接受语义风险不可识别。
- 用户聚焦或输入时，Agent 输入进入待发送队列。
- 输出仅保存在内存，关闭清除；默认导出为 `.txt`。
- 默认读取约 200 行，更多内容分段申请。

非阻塞默认值：

- 标签默认命名为 `Terminal 1`、`Terminal 2`。
- Agent 不得静默关闭存在前台程序的终端。
- Agent 仅在用户明确要求时创建或关闭终端。

当前无阻塞待定项。

## 7. 约束条件

- 首期仅服务 macOS Electron App。
- 终端能力必须限制在本机 App，不得通过局域网暴露任意命令执行接口。
- 终端进程使用当前用户权限，不引入额外提权。
- 不破坏上游 pi-web 的 Web 使用方式；非桌面环境应安全降级为无终端能力。
- 保持 PiPi Agent 品牌、深海极光主题及现有 Git 上游同步策略。
- 原生终端依赖和打包必须兼容 Apple Silicon、Electron 签名及当前安装方式。

## 8. 交付验收口径

- 手动输入、ANSI、窗口缩放、复制粘贴及至少三类目标 CLI 验证通过。
- 同项目多个终端可并行运行；切换聊天不终止，退出 App 后全部终止。
- Agent 能列出、读取和输入当前/指定终端；自然语言和 `/terminal` 均可用。
- 保护、信任、高风险确认、输入队列及强制接管路径均可完成。
- 搜索、重命名、导出可用，关闭后不残留输出记录。
- 非 Electron Web 模式不暴露终端接口。
- TypeScript、Lint、自动化测试、生产构建和 Electron 打包通过。
- 安装到 `/Applications/PiPi Agent.app` 后完成真实端到端验证。
